# راهنماهای کاربردی

هر راهنما به یک سؤالی که پروژه با آن روبه‌رو می‌شود جواب می‌دهد، با کمترین قدمی که
جوابش را بدهد. [راهنما](../guide.md) همه‌ی بخش‌ها را توضیح می‌دهد؛ این‌ها برای پروژه‌ای
است که در جریان است.

| راهنما | سؤال |
|---|---|
| [فرانت‌اند Next.js](nextjs.md) | صفحه‌های ما روی سرور هم رندر می‌شوند - کوکی‌ها کجا می‌روند؟ |
| [مهاجرت از توکن در `localStorage`](from-local-storage.md) | فرانت‌اند ما امروز توکن‌هایش را خودش نگه می‌دارد |
| [نگه داشتن سابقه](audit-trail.md) | چه کسی، از کجا وارد شد، و نشست چرا تمام شد |
| [خارج کردن یک شخص از همه‌جا](sign-out-everywhere.md) | گوشی دزدیده شده، یا رمز عوض شده |
| [تست پروژه‌ای که از آن استفاده می‌کند](testing.md) | کلاینت واردشده، توکن منقضی، تمدید |
